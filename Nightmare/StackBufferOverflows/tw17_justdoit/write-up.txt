Program meminta input argv berupa file lalu program meminta sebuah passowrd yang ternyata ketika dibedah, password yang benar adalah "P@SSW0RD". Namun tidak cukup sampai di situ, terdapat sebuah kerentanan buffer overflow pada input user di mana buffer menerima hanya 16 byte karakter namun fgets membaca sampai 32 byte karakter. 

Kerentanan tersebut dapat dimanfaatkan untuk menimpa variabel yang menghasilkan output message yaitu variabel yang berada pada ebp-0x14.

Jarak antara vulnBuf atau input user ke target atau output message adalah 20 byte (0x28 - 0x14), dengan demikian, jika ingin menimpa value dari variabel target, masukkan input acak sebanyak 20 byte, kemudian sisa nya ganti dengan address dari output yang kita inginkan.

Kita menginginkan address dari value flag dimana addressnya adalah 0804a080, maka dari itu, payload yang dibutuhkan adalah sebagai berikut:
python3 -c 'import sys; sys.stdout.buffer.write(b"A"*20 + b"\x80\xa0\x04\x08")' > input
./just_do_it < input
